# Mi Consola

Emulador web (PWA) de NES, Super Nintendo, Game Boy / Color, Game Boy Advance, Nintendo 64 y Nintendo DS que funciona en Safari de iPhone. Gratis, sin App Store ni jailbreak.

## Cómo usarla en el iPhone

1. Abre la web en **Safari**.
2. Pulsa **Compartir → Añadir a pantalla de inicio**. Se abre a pantalla completa como una app y Safari no borra tus partidas.
3. Pulsa **+ Añadir juego** y elige el archivo del juego desde la app Archivos.
4. Toca el juego y luego **Jugar**. Aparecen los botones táctiles en pantalla.

- La partida se guarda sola cada 30 segundos y al salir.
- Desde el menú (☰) del emulador puedes hacer guardados rápidos (estados), cambiar controles o usar un mando Bluetooth.
- Los juegos se guardan solo en tu iPhone, no se suben a ningún sitio.

Usa solo copias de juegos que tengas o juegos homebrew libres.

## Juegos gratis incluidos

La pestaña «Juegos gratis» trae 84 juegos homebrew de Game Boy, Game Boy Color y GBA con licencia libre. Autores y licencias en `juegos/CREDITOS.md`.

## Publicarla gratis con GitHub Pages

Sube esta carpeta a un repositorio público y activa **Settings → Pages → Deploy from a branch → main / (root)**. La web queda en `https://<usuario>.github.io/<repositorio>/`.

## Créditos

Emulación con [EmulatorJS](https://github.com/EmulatorJS/EmulatorJS) 4.2.3 y núcleos libretro (FCEUmm, Snes9x, Gambatte, mGBA, Mupen64Plus-Next, ParaLLEl N64, melonDS), con licencia GPL-3.0. Ver `data/LICENSE-EmulatorJS.txt`.
